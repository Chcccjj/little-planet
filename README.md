# 小星球

低多边形、绘本风的 Three.js 网页小游戏，致敬《小王子》里的小行星 B612。

星球半径约 5，带轻微地表起伏和平面着色。光照是柔和的半球光加上一盏暖色方向光（软阴影），背景是薄雾里的星空渐变。小王子是代码搭出来的低多边形占位人，站在球面上：脚底贴着地表，头顶始终沿着半径朝外，可以绕整颗星球走一圈，经过两极也不会翻面。相机跟在身后，用四元数跟着角色的「上」方向转，不会钻进地里。配色只用低饱和的莫兰迪色（雾霾蓝、薄雾灰、米白、灰鼠尾草、灰玫瑰），日落时转到暖灰粉和雾霾蓝紫，不用高饱和的红或黄。

球面上有玻璃罩下的玫瑰、三座火山（两座醒着，冒一点淡灰烟；一座休眠）、一棵猴面包树苗，和一把可以挪动的椅子。人走不过去，会被沿切向轻轻推开。走近时，桌面在物件上方写「E / 点击」，触屏写「轻触」。按 E 要站在旁边。用鼠标点一下，或用手指轻触画面里看得见、又没被星球挡住的物件，不论远近都会打开绘本式的对话框。椅子还会把天色慢慢换成日落，过一会儿自己走回来，可以再看一次；天色还没回来时再点，会轻轻说一声。

## 如何操作

- **W A S D** 或方向键：相对当前镜头朝向行走（W 是镜头看过去的方向）
- **按住鼠标左键拖动**：绕角色环顾。左右是绕角色头顶的偏航，上下是俯仰，俯仰有限位
- **滚轮**：在限定范围内拉近或拉远
- **走近物件**：桌面提示「E / 点击」，触屏提示「轻触」。按 **E** 只在这个范围内有用
- **点一下或轻触看得见的物件**：不需要走近。射线点中、而且没被星球挡住，就打开对话。轻触和点击走的是 pointerdown / pointerup，拖动不会误触
- **对话打开时**：走路会停住。点对话框、按 E 或空格，先把这一句补全，再翻下一页，最后一页之后关上

窄屏（比如竖着的手机）会按 `1 / 宽高比` 把镜头拉远，避免左右被裁掉。桌面像素比最高 2。触屏默认最高 1.5；屏幕很大、内存不超过 3 GB 时降到 1.25，只有一两个核心或内存不超过 2 GB 时降到 1。开起来大约两秒后，如果半秒窗口里的帧率连续两次低于 28，像素比再降 0.25，最低到 1，并且不会自己升回去。自动化浏览器不走这一档，免得读像素的时候画布正被改大小。

触屏上，左下角有一枚半透明的摇杆，按住它走路；手指在其余地方拖动是环顾，双指张开或捏合可以拉远、拉近。摇杆和环顾按 pointerId 分开，可以同时进行。轻点物件、对话框和椅子仍然会互动，拖动不会误触。对话打开时摇杆会藏起来，关上后再出现，并且不会留着刚才的推力。没有触控的桌面不显示摇杆，键鼠跟以前一样。

打开页面先是开始界面。没有存档时是「开始」，有存档时是「继续」和「重新开始」，下面用小字写已发现几处、看过几次日落。右上角可以暂停，Esc 也行。暂停时行走、环顾和天色都停住；切到别的标签页会自己暂停。菜单里可以回到开始界面，还有一个音效开关，只记住开或关，没有音频文件。

进度写在 `localStorage` 的 `little-planet.save.v1`：王子站在哪、朝向哪、已经互动过的物件、日落次数，以及音效开关。大约每 4 秒写一次，暂停或页面隐藏时也会写。读不到存储、版本对不上或 JSON 坏了，就当作没有存档。

## 如何运行

需要 Node.js 18 或更高版本。

```bash
npm install
npm run dev        # 本地开发服务器
npm run typecheck  # tsc --noEmit
npm run test       # Vitest：数学、存档、输入、对话状态
npm run test:e2e   # 先构建，再用 Playwright 打开 vite preview 做冒烟测试
npm run build      # 生产构建
npm run preview    # 预览生产构建
```

`vite.config.ts` 里的 `base` 是 `'./'`，构建结果可以挂到子路径上。入口只做 WebGL 检测，场景和 `three` 分开加载。`three` 仍是单独的 chunk。日落那张天空贴图要到第一次挪椅子时才画。玫瑰、火山和猴面包树苗合成一个网格来画，原来的网格留着做点击检测，只是不显示。

开发模式下，画面左上角有一块很小的性能面板，显示 FPS、draw calls（`renderer.info.render.calls`）和三角形数量。生产构建不会包含这块面板。浏览器没有 WebGL 时，会显示一张莫兰迪色的说明，而不是空白页。

## 上线地址

格式是 `https://<GitHub用户名>.github.io/<仓库名>/`。按预计的公开仓库 `Chcccjj/little-planet`，地址是：

https://chcccjj.github.io/little-planet/

页面在 `/little-planet/` 这个子路径下。相对路径会跟着当前目录走，所以地址末尾要有斜杠；GitHub Pages 访问不带斜杠的 `/little-planet` 时会先跳到带斜杠的地址。

首次启用：打开仓库 **Settings → Pages → Build and deployment → Source**，选择 **GitHub Actions**。之后推送到 `main` 会运行 `.github/workflows/deploy.yml`，也可以在 Actions 里手动运行 **Deploy GitHub Pages**。工作流只用仓库自带的 `GITHUB_TOKEN` 权限（`contents: read`、`pages: write`、`id-token: write`），不需要另加 secret。

拉取请求会跑 `.github/workflows/ci.yml`：类型检查、Vitest，以及 Playwright 冒烟测试（截图作为 Actions 构件）。推送到 `main` 仍由 `.github/workflows/deploy.yml` 做类型检查、构建和发布，不跑浏览器测试，避免拖住 Pages。`public/.nojekyll` 会进到 `dist`，避免 Pages 按 Jekyll 丢掉下划线开头的文件。

## 代码结构

- `src/input/`：每帧的移动向量 `(x, y)`、视角增量、滚轮或双指缩放。桌面键鼠和触屏摇杆都是 `InputDriver`，在 `createInput` 里加到同一帧。
- `src/ui/`：开始界面和暂停菜单，DOM 绘制，不占 draw call。
- `src/save/`：带版本号的 localStorage 存档。
- `src/interactions/`：距离检测、轻触（区分点击和拖动）、提示、逐字对话，以及日落。
- `src/character/`：小王子占位模型，以及球面行走。
- `src/camera/`：相对角色「上」方向的第三人称跟随相机。
- `src/world/`：星球、地表射线、道具、烟和碰撞球。
