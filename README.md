# 小星球

低多边形、绘本风的 Three.js 网页小游戏，致敬《小王子》里的小行星 B612。

星球半径约 5，带轻微地表起伏和平面着色。光照是柔和的半球光加上一盏暖色方向光（软阴影），背景是薄雾里的星空渐变。小王子是代码搭出来的低多边形占位人，站在球面上：脚底贴着地表，头顶始终沿着半径朝外，可以绕整颗星球走一圈，经过两极也不会翻面。相机跟在身后，用四元数跟着角色的「上」方向转，不会钻进地里。配色只用低饱和的莫兰迪色（雾霾蓝、薄雾灰、米白、灰鼠尾草、灰玫瑰），日落时转到暖灰粉和雾霾蓝紫，不用高饱和的红或黄。

球面上有玻璃罩下的玫瑰、三座火山（两座醒着，冒一点淡灰烟；一座休眠）、一棵猴面包树苗，和一把可以挪动的椅子。人走不过去，会被沿切向轻轻推开。走近时，桌面在物件上方写「E / 点击」，触屏写「轻触」。按 E 要站在旁边。用鼠标点一下，或用手指轻触画面里看得见、又没被星球挡住的物件，不论远近都会打开绘本式的对话框。椅子还会把天色慢慢换成日落，过一会儿自己走回来，可以再看一次；天色还没回来时再点，会轻轻说一声。

## 如何操作

- **W A S D** 或方向键：相对当前镜头朝向行走（W 是镜头看过去的方向）
- **按住鼠标左键拖动**：绕角色环顾。左右是绕角色头顶的偏航，上下是俯仰，俯仰有限位
- **滚轮**：在限定范围内拉近或拉远
- **走近物件**：桌面提示「E / 点击」，触屏提示「轻触」。按 **E** 只在这个范围内有用
- **点一下或轻触看得见的物件**：不需要走近。射线点中、而且没被星球挡住，就打开对话。轻触和点击走的是 pointerdown / pointerup，拖动不会误触
- **对话打开时**：走路会停住。点对话框、按 E 或空格，先把这一句补全，再翻下一页，最后一页之后关上

窄屏（比如竖着的手机）会按 `1 / 宽高比` 把镜头拉远，避免左右被裁掉。触控设备把像素比封顶在 1.5，桌面仍是 2。手机上的虚拟摇杆和触控环顾留到下一步，接进同一套输入接口即可。手指现在可以点开画面里看得见的物件、翻对话、挪椅子，还不能走路。

## 如何运行

需要 Node.js 18 或更高版本。

```bash
npm install
npm run dev        # 本地开发服务器
npm run typecheck  # tsc --noEmit
npm run build      # 生产构建
npm run preview    # 预览生产构建
```

`vite.config.ts` 里的 `base` 是 `'./'`，构建结果可以挂到子路径上，方便以后部署。`three` 被拆成单独的 chunk。

开发模式下，画面左上角有一块很小的性能面板，显示 FPS、draw calls（`renderer.info.render.calls`）和三角形数量。生产构建不会包含这块面板。浏览器没有 WebGL 时，会显示一张莫兰迪色的说明，而不是空白页。

## 代码结构

- `src/input/`：每帧的移动向量 `(x, y)`、视角增量、滚轮缩放。桌面键鼠在这里；之后的虚拟摇杆和触控拖拽实现同一个 `InputDriver`，从 `createInput` 里加进去。
- `src/interactions/`：距离检测、轻触（区分点击和拖动）、提示、逐字对话，以及日落。
- `src/character/`：小王子占位模型，以及球面行走。
- `src/camera/`：相对角色「上」方向的第三人称跟随相机。
- `src/world/`：星球、地表射线、道具、烟和碰撞球。
