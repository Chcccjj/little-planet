# little-planet

低多边形、绘本风的 Three.js 网页小游戏，致敬《小王子》里的小行星 B612。

这一版只是骨架：一颗半径约 5 的低多边形星球，带轻微地表起伏和平面着色；光照是柔和的半球光加上一盏暖色方向光（软阴影）；背景是薄雾里的星空渐变。相机绕着星球缓慢转一圈，作为占位，直到下一步加上行走。配色只用低饱和的莫兰迪色（雾霾蓝、薄雾灰、米白、灰鼠尾草、灰玫瑰），不用高饱和的红或黄。

## 如何运行

需要 Node.js 18 或更高版本。

```bash
npm install
npm run dev        # 本地开发服务器
npm run typecheck  # tsc --noEmit
npm run build      # 生产构建
```

`vite.config.ts` 里的 `base` 是 `'./'`，构建结果可以挂到子路径上，方便以后部署。

开发模式下，画面左上角有一块很小的性能面板，显示 FPS、draw calls（`renderer.info.render.calls`）和三角形数量。生产构建不会包含这块面板。

- **PR 4**：移动端虚拟摇杆、菜单，并用 localStorage 记住进度。
- **PR 5**：部署。
